# LP-Nav无人机自主导航算法技术报告

## 1. 算法概述

LP-Nav（Learning-based Predictive Navigation）是一种面向复杂三维环境的无人机端到端自主导航算法。该算法以近端策略优化（Proximal Policy Optimization, PPO）为策略学习主体，融合三维激光雷达、无人机运动状态、目标相对信息和动态障碍物状态，直接输出无人机三维速度指令。

算法重点解决两类具有代表性的导航难题：一类是高速动态障碍物带来的未来轨迹冲突，另一类是长墙、L形和U形等大型障碍物引发的局部最优与死锁。为此，LP-Nav将基于物理运动规律的三维速度障碍物风险与数据驱动的多时域预测表征相结合，使无人机不仅能响应当前观测，还能在策略特征中形成对未来碰撞、通行空间和导航趋势的预判。

该方法的突出特点是“训练阶段强化前瞻性，部署阶段保持轻量化”。三维VO风险和多时域监督在训练中帮助策略形成更成熟的避障行为；部署时仍由单个前馈策略直接产生动作，无需运行在线轨迹搜索、迭代优化或完整世界模型滚动预测，因而适合对实时性和计算资源要求较高的无人机平台。

## 2. 任务定义

算法的目标是在包含随机静态障碍物、运动障碍物和大型结构化障碍物的三维空间中，引导无人机从随机起点安全到达目标点。策略需要同时满足以下要求：

- 持续向目标区域取得有效进展；
- 提前避让具有潜在碰撞趋势的动态障碍物；
- 在大型障碍物前选择合理的侧向或高度绕行路径；
- 避免长时间悬停、反复试探和局部死锁；
- 必要时允许短暂后退，以换取更安全的后续通道；
- 保持动作平滑和合理飞行高度；
- 在有限时间内完成导航任务。

与只追求瞬时最短路径的策略不同，LP-Nav更关注整个导航过程的长期可行性。算法允许无人机暂时牺牲局部目标进展，换取更大的安全净空和更可靠的全局到达概率。

## 3. 总体算法框架

LP-Nav由环境感知、共享特征提取、Actor-Critic策略、多时域辅助预测和奖励评价五部分组成。

```text
                         +----------------------+
三维LiDAR -------------->| LiDAR卷积编码器       |---+
                         +----------------------+   |
                                                     |
无人机状态与目标信息 -------------------------------+--> 256维共享特征 z_t
                                                     |         |
                         +----------------------+   |         +--> Actor --> 三维速度动作
动态障碍物状态 --------->| 动态障碍物MLP编码器   |---+         |
                         +----------------------+             +--> Critic --> 状态价值
                                                               |
当前动作 ------------------------------------------------------+--> 多时域辅助预测头
                                                                    （仅训练时使用）

环境状态转移 --> 导航奖励 + 安全奖励 + 3D-VO风险 + 死锁相关奖励
                                     |
                                     +--> PPO回报、优势与联合损失
```

共享编码器是整个框架的核心。Actor利用共享特征决定下一步动作，Critic利用同一特征评估状态价值，辅助预测头则要求该特征同时保留未来安全状态和导航结果。三类学习信号共同作用，使特征表示不只是对当前观测的压缩，还成为包含潜在风险和短期发展趋势的决策表征。

## 4. 多模态状态表示

### 4.1 三维激光雷达

算法使用水平360度、36个水平采样方向和4个垂直波束的三维LiDAR观测，最大感知距离为4 m。LiDAR数据经过三层卷积网络，提取障碍物边缘、局部开口、前方净空和空间连续性等几何特征，最终形成128维编码。

三维LiDAR使策略能够区分平面障碍物、具有高度差的障碍物和可从上方或侧方绕行的空间结构，是实现三维自主避障的基础。

### 4.2 无人机与目标状态

无人机状态使用8维紧凑表示，包括：

- 目标方向单位向量；
- 无人机与目标的水平距离；
- 无人机与目标的垂直距离；
- 目标坐标系下的三维飞行速度。

目标坐标系随无人机当前位置持续更新，使网络始终以“面向当前目标方向”的方式理解速度和障碍物分布。该表示降低了世界坐标变化对策略学习的干扰，有利于策略迁移到不同起点、终点和地图区域。

### 4.3 动态障碍物状态

策略选取附近5个动态障碍物，每个障碍物使用10维特征描述，包括相对方向、水平距离、垂直距离、三维速度以及几何尺寸类别。动态障碍物状态通过独立MLP提取为64维特征。

相对位置与相对速度的联合输入，使策略能够区分“距离较近但正在远离”和“距离尚远但正在快速逼近”等不同交互状态，而不是把所有近距离障碍物视为同等危险。

### 4.4 特征融合与动作生成

LiDAR特征、无人机状态和动态障碍物特征经拼接后输入融合MLP，得到256维共享特征。Actor基于Beta分布输出有界三维速度动作，当前速度上限为2 m/s。局部目标坐标系动作随后被转换至世界坐标系，并通过速度控制器映射为无人机底层控制量。

Beta分布天然适合有界连续动作，可减少高斯动作裁剪带来的边界失真；目标坐标系动作则使策略更关注“前进、后退、侧移和升降”等相对导航行为。

## 5. 面向任务完成的奖励设计

LP-Nav的总奖励由基础安全约束、目标进展、停滞抑制、逃脱激励、三维VO风险和终止代价组成：

```math
R_t=R_{base}+R_{progress}+R_{stall}+R_{escape}+R_{VO}+R_{terminal}.
```

### 5.1 目标进展与到达奖励

目标进展奖励由相邻两步目标距离变化计算：

```math
R_{progress}=w_p(d_{t-1}-d_t).
```

无人机接近目标时获得连续正反馈，远离目标时产生负反馈；进入0.5 m目标范围后给予50的到达奖励，超时则施加45的惩罚。连续进展与终点奖励结合，使策略既有明确的局部方向，也不会忽略最终任务完成。

当无人机前方受阻时，短暂后退只按正常负进展的0.1倍惩罚。这一设计为复杂绕行保留了必要的动作自由度：策略可以先退出危险区域，再选择新的通道，而不必在“继续向前碰撞”和“停止不动”之间被迫选择。

### 5.2 静态与动态净空约束

当静态或动态障碍物进入1.1 m安全范围时，系统根据侵入程度施加连续惩罚。该奖励提供稳定的近场安全约束，促使无人机与障碍物保持基本净空，同时避免远距离障碍物持续主导总回报。

### 5.3 动作平滑与高度约束

相邻时刻速度变化会产生平滑惩罚，抑制高频振荡和突变控制。高度奖励允许无人机在目标高度附近一定范围内自由调整，只有高度偏差超过0.4 m后才施加二次惩罚。因此，无人机仍保留利用三维空间避障的能力，而不是被严格限制在固定高度平面。

### 5.4 停滞检测与渐进惩罚

系统综合位移、速度和目标进展判断停滞。当无人机在连续窗口内移动距离过小、速度过低且没有取得有效进展时，停滞计数器持续增加，并逐步增强负奖励。渐进惩罚比瞬时硬阈值更平滑，能够减少误判，同时有效抑制长期悬停。

### 5.5 死锁恢复激励

算法利用前方障碍物和目标进展维护受阻状态。当受阻计数下降时给予逃脱奖励，显式鼓励无人机解除死锁。该机制关注的不只是“是否陷入困境”，更关注“是否采取了有效恢复动作”，有利于形成后退、侧移、改变高度和重新绕行等连续行为。

## 6. TTC感知的三维VO风险建模

### 6.1 未来轨迹冲突

设动态障碍物相对无人机的位置为 `p_r`，相对速度为 `v_r`：

```math
p_r=p_{obs}-p_{uav}, \qquad v_r=v_{obs}-v_{uav}.
```

根据障碍物三维尺寸和安全裕度构造尺度矩阵 `D`。未来相对轨迹进入安全椭球的条件为：

```math
\left\|D^{-1}(p_r+v_rt)\right\|_2^2\le 1.
```

算法将该条件展开为一元二次方程，解析计算首次进入安全区域的时间TTC。只有障碍物处于接近状态、未来轨迹存在有效交点且TTC位于2.1 s预测范围内时，才产生VO风险。

这种判断并不只看障碍物是否靠近，而是判断双方继续保持当前运动趋势后是否真正发生空间冲突，因此能够显著提高动态避障的提前量和针对性。

### 6.2 风险分级

对于有效风险，采用指数形式进行连续分级：

```math
\rho_{VO}=\exp(-TTC/\tau), \qquad R_{VO}=-w_{VO}\max_i\rho_{VO}^{(i)}.
```

当前 `tau=0.75`、VO权重为1.3。即将碰撞的障碍物获得更高风险，仍有充分反应时间的障碍物只产生较弱约束。策略因此能够优先处理最紧迫的冲突，而不是对感知范围内所有障碍物进行同等强度的保守避让。

### 6.3 高度相关球体表示

对于高度较大的动态障碍物，算法沿垂直方向进行稀疏球体分解。球体间距依据障碍物水平尺度确定，球半径由水平对角尺寸计算。随后根据无人机与障碍物在预测窗口中的垂直相对运动，筛除与无人机飞行高度无关的球体。

这一设计具有三方面价值：

- 比单一大椭球更准确地描述细长障碍物；
- 避免将高度错开的障碍物误判为严重风险；
- 相较高密度几何分解保持较低计算负担。

### 6.4 渐进式风险注入

VO奖励在训练前20000步内逐渐增加至完整权重。策略首先学习基本目标导航，再逐步建立动态风险意识，可避免训练早期因安全惩罚过强而形成过度保守或静止策略。

## 7. 多时域预测表征学习

### 7.1 轻量预测机制

LP-Nav借鉴世界模型“利用未来状态监督当前表征”的思想，但不构建完整环境生成模型。辅助预测器以共享特征 `z_t` 和当前动作 `a_t` 为输入：

```math
\hat{y}_{t,k}=f_{aux}(z_t,a_t), \qquad k\in\{1,3,5\}.
```

监督标签取自当前观测—动作对之后的同一段PPO采集轨迹。更准确地说，该预测近似描述

```math
\hat{y}_{t,k}\approx\mathbb{E}_{\pi_b}\left[Y_{t:t+k}\mid o_t,a_t\right],
```

其中后续动作由生成该rollout的采集策略 `\pi_b` 产生。因此，它预测的是当前观测—动作对之后、在后续策略执行下的条件轨迹结果，而不是当前动作的独立因果效应，也不比较多个候选动作或执行反事实规划。

预测范围覆盖未来1步、3步和5步，使特征同时关注即时风险和更长时间尺度的导航趋势。

### 7.2 预测目标

每个预测时间尺度包含四类监督目标：

- 未来是否发生碰撞；
- 未来是否进入卡死状态；
- 未来最小前向净空；
- 未来累计目标进展。

碰撞和卡死描述安全事件，最小净空描述路径可通行程度，累计进展描述动作对任务完成的长期贡献。四类目标共同约束共享特征，避免网络只记住局部几何而忽略导航结果。

### 7.3 联合训练目标

碰撞和卡死采用二元交叉熵损失，净空和进展采用Smooth L1损失。辅助损失以0.1权重加入PPO目标：

```math
L=L_{actor}+L_{critic}+L_{entropy}+0.1L_{aux}.
```

该训练方式使Actor和Critic受益于更具预测性的共享特征，但不会强迫策略直接服从某个手工规划动作。策略仍可根据环境选择多种可行绕行方式，保持强化学习方法的灵活性。

### 7.4 对大型障碍物的作用

大型障碍物的难点往往不是下一步是否碰撞，而是连续若干步后是否会出现净空下降、进展停滞和无路可走。多时域预测任务将这些未来结果显式反馈给当前特征，使无人机能够更早识别不利运动趋势，并在接近障碍物深处之前选择侧向绕行或调整高度。

因此，该机制本质上提升了策略对“未来可通行性”的感知能力，有助于减少在长墙中心反复试探、进入U形结构后无法退出以及在障碍物前持续悬停等局部最优现象。

## 8. 面向复杂环境的训练任务设计

训练环境支持随机离散障碍物、单面墙、多面墙、L形墙和U形墙等多种结构。通过不同墙体组合，可以逐步增加环境拓扑复杂度，覆盖直接穿越、侧向绕行、提前选边和死锁恢复等行为。

训练采用边界随机跨越式任务：起点从地图边界采样，终点从起点所在边之外的其余边界采样，并检查起终点附近是否具备安全净空。这种设计显著提高了轨迹穿越核心障碍物区域的概率，使采样数据真正包含避障决策，而不是大量消耗在地图边缘的空旷直线飞行中。

Isaac Sim GPU并行环境能够同时收集大量轨迹。仿真时间步长为0.016 s，对应62.5 Hz更新频率；每次PPO rollout包含32步数据。高吞吐采样使策略能够经历丰富的障碍物位置、速度、尺寸和交互组合，为复杂环境泛化奠定数据基础。

训练端还预留了观测延迟、动作延迟、执行误差、LiDAR噪声、量化误差以及动态目标检测误差与丢帧等随机化接口。当前模型启用了动作执行误差，后续可根据实际飞行平台测得的误差分布进一步配置，从而系统性缩小仿真与部署之间的差异。

## 9. 算法特点与核心优势

### 9.1 具有前瞻性的动态避障能力

算法不等到障碍物进入近距离危险区才开始处理，而是通过TTC提前判断未来运动冲突。面对横穿、迎面接近或斜向高速运动的障碍物时，策略可以获得更充足的调整时间，从而减少急转、骤停和末时刻碰撞。

### 9.2 兼顾安全性与通行效率

风险强度随TTC连续变化，不会对所有障碍物施加相同约束。安全运动趋势不会受到过度惩罚，真正紧迫的风险则被优先处理。这种风险分级有助于避免“为了安全而完全不动”的保守策略，在安全性和导航效率之间形成更合理的平衡。

### 9.3 适合真实三维空间

算法同时处理水平和垂直相对运动，并利用高度相关球体描述动态障碍物。无人机可以根据环境选择侧向绕行、升高或降低，而不是局限于二维平面上的左右避障。

### 9.4 对大型与凹形障碍物具有更强适应性

多时域预测表征使策略能够关注未来净空和累计进展，提前发现短期安全但长期不利的动作。结合停滞惩罚和逃脱奖励，算法能够形成更加果断的绕行与恢复行为，降低长墙、L形和U形结构引起的局部死锁。

### 9.5 允许必要的后退与重新规划行为

受阻时降低后退惩罚，使策略不会被目标进展奖励机械地推向障碍物。无人机可以主动拉开距离，重新获得观察和转向空间，再选择新的路径。这种行为更接近真实导航中的有效决策，而不是单一的“永远朝目标前进”。

### 9.6 训练过程可解释、可诊断

系统分别记录VO风险、碰撞、前向净空、目标进展、停滞、死锁和恢复等指标。研究者可以判断性能瓶颈来自动态风险预测不足、几何感知不足还是长期决策不足，为奖励权重调整、模型消融和失败案例分析提供清晰依据。

### 9.7 部署阶段保持低开销

辅助预测头只用于训练共享表征，部署时无需执行。最终控制仍然是一次特征提取和Actor前向传播，不需要在线采样候选轨迹或求解复杂优化问题。这使算法能够在保留预测性行为的同时满足无人机高频实时控制需求。

### 9.8 具有良好的工程扩展性

训练环境、障碍物复杂度、VO参数、辅助任务权重和噪声模型均由配置文件控制。算法可以方便地扩展到不同地图规模、动态障碍物密度、传感器误差和飞行速度范围，也便于开展课程训练、参数敏感性分析和面向具体平台的再训练。

## 10. 实验表现与实际意义

仿真和实物飞行实验验证了算法在复杂障碍物环境中的有效性。在动态障碍物导航对比实验中，LP-Nav的成功率从74.3%提升至84.6%，即绝对提高10.3个百分点；在大型障碍物场景中，算法同时表现出死锁率下降和死锁后恢复能力增强。

这些结果说明，算法获得的并非单一场景下的碰撞规避规则，而是一种能够综合理解当前空间、相对运动和未来导航趋势的策略能力。3D-VO为策略提供物理一致的动态风险先验，多时域预测任务则使策略学习到更有决策价值的潜在表示。二者协同后，无人机能够在快速变化和结构复杂的环境中做出更早、更稳健且更具连续性的动作选择。

从工程角度看，LP-Nav把较复杂的未来风险学习集中在离线训练阶段，将部署阶段压缩为轻量前馈决策。这种设计既充分利用大规模仿真训练的计算能力，又避免将计算压力转移到机载平台，为动态环境中的实时自主飞行提供了具有实践价值的解决方案。

## 11. 算法贡献总结

LP-Nav的主要贡献可以归纳为以下四点：

1. 构建TTC感知的三维速度障碍物风险奖励，使策略能够依据相对位置、相对速度和障碍物几何形状提前规避未来碰撞。
2. 设计高度相关的稀疏球体障碍物表示，在提高三维风险表达精度的同时控制计算复杂度。
3. 提出动作条件的多时域预测辅助学习，同时预测碰撞、卡死、前向净空和目标进展，增强策略对大型障碍物和局部最优的处理能力。
4. 形成训练增强、部署轻量的端到端导航体系，在不增加在线规划过程的条件下提高动态避障成功率、复杂结构绕行能力和死锁恢复能力。

## 12. 总结

LP-Nav以端到端强化学习为主体，将可解释的三维运动风险和轻量预测表征融入统一训练过程。算法既能利用深度策略学习复杂环境中的灵活行为，又通过VO运动先验增强动态安全性，并通过多时域监督改善大型障碍物场景中的长期决策。

其核心价值在于：无人机部署时仍然能够快速、直接地产生动作，但这种快速反应并非简单的条件反射，而是经过大量未来风险和导航结果监督所塑造的预测性决策能力。由此，算法在动态避障、复杂绕行、死锁恢复、实时执行和工程扩展之间取得了较为完整的平衡。



你的两大贡献最好分别对应两个核心问题：

这两项工作分别对应无人智能体规控领域中两个比较核心、且尚未完全解决的问题：

## 1. 动态三维环境中的预测性安全决策

当前许多学习型避障方法仍偏向“反应式决策”：根据障碍物当前距离判断危险。它们面临几个问题：

- 当前距离不能反映未来碰撞趋势；
- 相同距离下，迎面接近与逐渐远离的风险完全不同；
- 许多VO方法基于二维平面，无法准确表达无人机的升降自由度；
- 纯神经网络策略缺少明确的运动学先验，可能需要大量样本才能学会动态交互规律；
- 过强的距离惩罚又容易导致无人机过度保守，影响通行效率。

你的3D-VO贡献针对的是：

> **如何使无人机在复杂三维动态交互中，依据未来轨迹冲突而不是当前距离，提前作出兼顾安全性与机动性的决策。**

它通过相对位置、相对速度、三维几何和TTC，把“是否危险”转化为具有物理意义的连续未来风险。高度相关球体表示则进一步缓解二维近似和粗糙三维包络带来的误判。

这个挑战可以概括为：

> **Predictive safety-aware decision-making under dynamic 3D interactions.**

## 2. 局部观测下的长期推理与局部最优

PPO等无模型强化学习策略通常根据当前观测直接输出动作。虽然长期回报会间接影响训练，但共享特征没有被明确要求理解未来状态。这会带来：

- 策略容易关注下一步是否安全，而忽略连续执行后的结果；
- 面对长墙时，可能一直向墙体中心接近，直到无路可走；
- 面对L形和U形障碍物时，容易反复试探、悬停或陷入局部死锁；
- 绕行可能要求暂时远离目标，但短视策略通常不愿后退；
- 完整世界模型、MPC或在线轨迹搜索虽然具有前瞻性，却会增加计算量和决策延迟。

你的多时域辅助学习针对的是：

> **如何在不引入高开销在线规划的情况下，让端到端策略获得对未来风险、可通行性和任务进展的长期判断能力。**

通过预测当前观测—动作对之后、在后续策略执行下出现的碰撞、卡死、最小净空和累计进展，辅助目标促使编码器保留与未来安全性和可通行性相关的信息。这有助于策略提前绕行、接受必要退让，并降低大型凹形障碍物引起的局部最优。

这个挑战可以概括为：

> **Long-horizon reasoning and local-minimum mitigation without online planning overhead.**

## 更高层次的意义

两项贡献共同回答了无人智能体规控中的一个重要问题：

> 如何让智能体既具有模型自由策略的实时反应能力，又具备基于运动学规律和未来结果的预测决策能力？

你的方法给出的答案是：

```text
3D-VO物理先验
    → 提供可解释的未来动态碰撞风险

多时域预测监督
    → 塑造理解未来可通行性和任务结果的策略表征

训练阶段联合学习
    → 将预测能力内化进策略

部署阶段移除辅助头
    → 保持端到端实时决策
```

## 论文式英文表述

可以在Introduction中这样概括：

> The proposed method addresses two fundamental challenges in learning-based autonomous navigation. The first is predictive safety-aware decision-making under dynamic three-dimensional interactions, where instantaneous obstacle clearance is insufficient to characterize future collision risk. The second is long-horizon navigation reasoning under local observations, particularly when large and concave obstacles require temporary retreat or extended detours. By combining physics-informed 3D velocity-obstacle shaping with lightweight multi-horizon predictive representation learning, our method improves both proactive dynamic-obstacle avoidance and local-deadlock mitigation without introducing additional online planning overhead.

最精炼地说，你的两个突破分别解决：

1. **不是等障碍物靠近才躲，而是提前判断未来会不会撞。**
2. **不是只判断下一步能不能走，而是判断继续这样走会不会被困住。**







你的奖励函数不是单纯的“稀疏奖励”或“密集奖励”，而是一个比较完整的**分层式混合奖励结构**：

```text
任务结果层：到达、碰撞、越界、超时
导航进展层：目标距离变化
预测安全层：3D-VO未来碰撞风险
即时安全层：静态/动态障碍物净空
行为恢复层：停滞惩罚、受阻逃脱奖励
控制约束层：动作平滑、高度约束
```

这种结构的主要优势如下。

## 1. 稀疏奖励与密集奖励相结合

如果只使用到达目标 `+50`、碰撞 `-45` 这类稀疏奖励，训练初期大量轨迹都无法到达目标，策略很难判断中间动作是好是坏，信用分配困难。

你的奖励函数同时保留了：

| 类型 | 奖励项 | 作用 |
|---|---|---|
| 稀疏结果奖励 | 到达、碰撞、越界、超时 | 明确最终任务目标 |
| 密集进展奖励 | `reward_goal_progress` | 每一步反馈是否接近目标 |
| 条件密集安全奖励 | 静态/动态净空、`reward_vo` | 危险形成时连续反馈 |
| 半密集行为奖励 | `reward_stall`、`reward_escape` | 对停滞积累和恢复过程反馈 |
| 密集正则奖励 | 平滑、高度约束 | 改善动作质量 |

因此，它既能利用密集反馈加速收敛，又通过稀疏终止奖励保证策略不会偏离“安全到达目标”这个根本任务。

## 2. 奖励覆盖了不同时间尺度

当前奖励并不只评价一个时间尺度：

- 静态/动态净空惩罚关注当前时刻是否过近；
- 3D-VO关注未来约2.1秒内是否存在碰撞趋势；
- 目标进展关注连续运动是否有效；
- 停滞计数关注一段时间内是否没有移动；
- 死锁恢复奖励关注策略能否从持续受阻状态中退出；
- 到达和超时评价完整回合结果。

这形成了从“当前安全”到“未来风险”，再到“长期任务完成”的多时间尺度监督。相比只根据当前距离或单步速度设计奖励，更适合复杂导航任务。

## 3. 采用“软约束＋硬约束”的安全结构

接近障碍物时，净空惩罚和VO惩罚会连续增加，属于软约束；真正碰撞后则直接扣除45并终止回合，属于硬约束。

这种结构的优点是：

- 在碰撞发生前提供方向明确的梯度；
- 不会只在碰撞瞬间才告诉策略动作错误；
- 又通过终止惩罚明确区分“接近风险”和“实际失败”；
- 允许策略在安全边界附近探索，而不是对所有障碍物一律极端回避。

可以概括为：

> Continuous risk shaping guides avoidance before failure, while sparse terminal penalties preserve strict safety boundaries.

## 4. 目标进展奖励比单纯速度奖励更合理

当前代码中 `reward_vel` 实际乘以0，主要导航动力来自：

```math
R_{progress}=w_p(d_{t-1}-d_t).
```

它直接评价无人机是否缩短了与目标之间的距离，而不是只评价速度是否指向目标。

这种设计的优势是：

- 与最终到达任务更一致；
- 不会单纯鼓励高速飞行；
- 侧向绕行只要最终产生有效进展，仍能获得累计收益；
- 相邻距离差在回合中具有近似望远镜求和性质，整体回报与实际到达进展紧密相关；
- 减少速度奖励和目标进展奖励重复叠加造成的过度激进。

## 5. 对“必要后退”采用情境化处理

普通目标进展奖励会惩罚所有远离目标的动作，但大型障碍物和动态障碍物避让经常需要短暂后退。

你的代码在前方受阻时，将后退惩罚缩小到正常值的0.1倍。这不是完全取消方向约束，而是允许策略在危险状态下暂时牺牲局部进展。

它解决了一个典型奖励冲突：

```text
继续前进：目标奖励较高，但可能碰撞
主动后退：有利于避障，但被目标奖励惩罚
停止不动：两种惩罚暂时都较小
```

降低受阻时的后退代价后，策略更可能选择“后退—侧移—重新绕行”，而不是悬停或强行前进。

## 6. 停滞惩罚和逃脱奖励形成正负配对

当前设计不是只有“陷入死锁就惩罚”，而是同时包含：

- `reward_stall`：持续不动、速度低且没有进展时逐渐惩罚；
- `reward_escape`：受阻计数下降时给予正奖励。

两者构成完整的行为塑造：

```text
持续停滞 → 负反馈
开始解除受阻 → 正反馈
重新取得进展 → 目标进展奖励
最终到达 → 稀疏大额奖励
```

这比单纯增加死锁惩罚更合理。只有负反馈可能让策略知道“不能停”，却不知道“怎样做才对”；逃脱奖励则为恢复动作提供了正向学习信号。

## 7. VO奖励是“风险分级”，不是统一惩罚

`reward_vo` 根据TTC采用指数风险：

```math
R_{VO}=-w_{VO}\exp(-TTC/\tau).
```

因此：

- TTC很短时惩罚强；
- TTC较长时惩罚弱；
- 不存在未来轨迹冲突时不惩罚；
- 已经进入安全包络时风险达到最大。

它避免了“所有感知到的动态障碍物都同样危险”的粗糙设计，使策略能够把注意力集中在最紧迫的动态冲突上，从而改善安全性与机动性之间的平衡。

## 8. VO权重采用渐进式引入

VO奖励在前20000个训练步内逐渐增大，而不是从训练开始就使用完整权重。

其训练逻辑是：

```text
训练前期：先学会基本飞行与目标导航
训练中期：逐渐学习动态风险判断
训练后期：形成完整的预测避障策略
```

这可以降低训练初期安全惩罚过强导致的静止策略和局部保守最优，是一种轻量的奖励课程设计。

## 9. 奖励项具有较好的物理与行为可解释性

每个主要奖励项都对应明确行为：

- `reward_goal_progress`：是否接近目标；
- `penalty_safety_static`：是否过度接近静态障碍物；
- `penalty_safety_dynamic`：是否过度接近动态障碍物；
- `reward_vo`：未来是否存在动态碰撞趋势；
- `reward_stall`：是否长期停滞；
- `reward_escape`：是否从受阻状态恢复；
- `penalty_smooth`：动作是否剧烈变化；
- `penalty_height`：高度是否明显偏离目标高度。

这使训练过程更容易诊断。比如碰撞率高但VO风险低，可能是风险模型范围不足；死锁率高但停滞惩罚接近0，可能是停滞阈值不合理。

## 报告式总结

可以在报告或论文中写成：

> 本文采用分层式混合奖励设计，将稀疏任务结果、密集目标进展、即时几何安全、未来动态风险以及停滞恢复行为统一到同一强化学习目标中。稀疏到达和失败奖励用于锚定最终导航目标，密集进展与净空反馈缓解长时域信用分配困难，TTC感知的三维VO奖励进一步提供未来碰撞风险监督。同时，情境化后退处理、渐进停滞惩罚和逃脱奖励允许策略学习必要的退让与重新绕行行为。该结构在目标导向、安全约束、动态避障和局部死锁恢复之间建立了多时间尺度的协同反馈。
