# LP-Nav训练端算法设计与优势报告

## 1. 项目概述

本项目面向同时包含静态障碍物、动态障碍物以及大型复杂障碍物的无人机自主导航任务，在NavRL的基础上提出基于学习的预测式导航框架（Learning-based Predictive Navigation, LP-Nav）。算法仍以近端策略优化（Proximal Policy Optimization, PPO）为基本训练框架，但不再仅依赖当前时刻的障碍物距离塑造策略，而是从两个层面赋予策略更强的前瞻性：一方面，在奖励函数中引入基于三维速度障碍物的未来碰撞风险；另一方面，引入受世界模型启发的多时域预测辅助学习，使共享特征能够编码未来安全状态和导航结果。

该方法的核心思想是：不仅让无人机知道“现在离障碍物多远”，还要使其在训练过程中逐渐学会判断“按照当前运动趋势继续飞行，未来是否会发生碰撞、停滞或陷入局部死锁”。这种由训练塑造出的预测性避障能力能够直接内化到策略网络中，在部署阶段无需额外执行在线轨迹搜索或世界模型滚动预测，从而兼顾导航性能和实时性。

仿真与实物实验表明，LP-Nav相较原始NavRL在动态障碍物环境中的导航成功率从74.3%提升至84.6%，即绝对提高10.3个百分点，同时在大型障碍物环境中表现出更低的死锁倾向和更强的死锁后恢复能力。

## 2. 研究问题与设计动机

原始NavRL通过激光雷达、无人机状态和动态障碍物状态直接输出速度指令，具有结构简洁、推理快速和易于部署等优点。然而，其安全奖励主要建立在当前净空距离上。此类即时距离信号能够告诉策略“障碍物已经很近”，却难以充分描述以下两类风险：

1. 动态障碍物当前距离较远，但其相对运动方向已经形成潜在碰撞关系。仅依赖距离会导致避障动作启动较晚。
2. 面对长墙、L形或U形等大型结构时，局部动作在短时间内可能是安全的，但连续执行后会进入无路可走或反复徘徊的状态。单步反馈难以支持长距离绕行决策。

针对上述问题，本项目保留NavRL端到端策略的实时性，同时向训练过程注入显式的运动学先验和多步未来监督。三维VO奖励负责提升动态避障的提前量，多步预测辅助任务负责提升共享表征对未来风险和长期导航趋势的敏感性，两者分别从奖励塑造和表示学习两个角度增强策略。

## 3. 总体框架

训练端总体数据流如下：

```text
Isaac Sim并行环境
    |
    +-- LiDAR观测 ----------------> CNN编码器 --------+
    +-- 无人机与目标状态 ----------------------------+--> 共享特征 z_t
    +-- 动态障碍物状态 -----------> MLP编码器 --------+        |
                                                               +--> Beta Actor --> 目标坐标系速度 --> 世界坐标系速度
                                                               |
                                                               +--> Critic --> 状态价值 V(s_t)
                                                               |
                                                               +--> 多时域预测头（仅训练）
                                                                    预测碰撞/卡死/净空/目标进展

环境反馈 --> 基础导航奖励 + 3D-VO未来风险奖励 --> PPO回报与优势估计

PPO损失 + 多时域辅助损失 --> 联合更新共享编码器、Actor与Critic
```

该框架没有把辅助预测结果直接拼接到Actor输入中。Actor始终基于共享特征输出动作，而辅助任务通过反向传播改善共享编码器。因此，预测能力被压缩进策略表征，部署时可以移除辅助分支，不改变在线策略的动作生成流程。

## 4. 状态、观测与动作表示

### 4.1 无人机与目标状态

无人机内部状态由8维向量构成，包括目标方向单位向量、目标水平距离、目标高度差以及目标坐标系下的三维速度。目标坐标系会根据无人机当前位置到目标点的方向逐步更新，使输入表达与ROS部署端的目标方向处理保持一致。

### 4.2 激光雷达观测

训练端采用水平36束、垂直4束的三维激光雷达表示，最大量程为4 m。LiDAR张量通过三层卷积网络提取局部几何特征，并映射为128维表示。卷积结构能够从距离阵列中识别障碍物边缘、开口和近场几何关系，为静态避障与大型结构绕行提供基础信息。

### 4.3 动态障碍物观测

策略接收最近5个动态障碍物的信息。每个障碍物使用10维状态描述，包含目标坐标系下的相对方向、水平与垂直距离、三维速度以及尺寸类别。动态障碍物信息经MLP编码为64维特征。

### 4.4 共享特征与动作输出

LiDAR特征、8维无人机状态和动态障碍物特征经过拼接与MLP融合，得到256维共享特征 `z_t`。Actor采用Beta分布产生有界速度动作，动作上限为2 m/s；随后将目标坐标系中的动作旋转到世界坐标系，并由速度控制器转换为无人机底层执行量。Critic从同一共享特征估计状态价值。

这种多模态结构兼顾了几何感知、目标导向和动态交互信息，同时保持了较小的网络规模，适合高频控制与机载部署。

## 5. 奖励函数设计

当前有效总奖励可以概括为：

```math
R_t = R_{base} + R_{progress} + R_{escape} + R_{stall} + R_{VO} + R_{terminal}.
```

其中，基础奖励包含每步生存项、静态与动态障碍物近距离惩罚、动作平滑惩罚和高度偏差惩罚。当前代码中的速度奖励系数为0，因此真正驱动目标运动的是距离进展奖励，而不是简单鼓励始终朝目标方向高速飞行。

### 5.1 目标进展奖励

以相邻时刻目标距离的减少量作为连续反馈：

```math
R_{progress}=w_p(d_{t-1}-d_t).
```

到达目标后给予显著终点奖励，超时则施加终止惩罚。当前配置的目标判定半径为0.5 m，到达奖励为50，目标进展系数为35，超时惩罚为45。

当无人机前方存在障碍物且短暂后退时，负进展只按0.1倍计入。这一设计允许策略为了避障进行必要的退让或侧向调整，避免“只要远离目标就强烈受罚”所导致的原地悬停和保守行为。

### 5.2 停滞惩罚与逃脱奖励

系统同时维护停滞计数器和受阻计数器。当无人机在一定窗口内位移小、速度低且目标进展不足时，逐步增加停滞惩罚。与单次硬惩罚相比，渐进式惩罚能够更平稳地抑制长期悬停。

当无人机在障碍物前方的受阻计数下降时，系统给予逃脱奖励。这意味着策略不仅会因“陷入死锁”受到负反馈，还能因“从受阻状态中恢复”获得正反馈，从而主动学习后退、侧移和重新选择绕行方向等恢复行为。

### 5.3 终止惩罚

发生碰撞时额外惩罚45，飞行高度低于0.2 m或高于4 m时额外惩罚20，并终止当前回合。明确的终止代价使成功到达目标成为比冒险穿越障碍物更优的长期策略。

## 6. TTC感知的三维速度障碍物奖励

### 6.1 从即时距离到未来碰撞风险

原始距离奖励主要依据障碍物当前距离进行评价。LP-Nav进一步考虑无人机和动态障碍物的相对运动。设障碍物相对位置和相对速度分别为：

```math
p_r=p_{obs}-p_{uav}, \qquad v_r=v_{obs}-v_{uav}.
```

根据障碍物水平尺寸、垂直尺寸和安全裕度构造三维尺度矩阵 `D`，并在归一化空间中判断未来轨迹是否进入安全椭球：

```math
\left\|D^{-1}(p_r+v_rt)\right\|_2^2 \le 1.
```

将其展开为关于时间 `t` 的一元二次方程后，可以解析求得首次进入安全区域的碰撞时间TTC。只要障碍物正在接近、方程存在有效交点，并且TTC位于2.1 s预测窗口内，就认为存在VO风险。

### 6.2 连续风险与奖励塑造

风险不是统一的二值惩罚，而是随TTC连续变化：

```math
\rho_{VO}=\exp(-TTC/\tau), \qquad R_{VO}=-w_{VO}\max_i \rho_{VO}^{(i)}.
```

当前参数 `tau=0.75`、`w_VO=1.3`。TTC越短，风险越接近1，惩罚越强；仍有较长反应时间的障碍物只产生较弱惩罚。该机制能够区分“虽然在感知范围内但运动趋势安全”的障碍物和“距离尚远但正在高速逼近”的障碍物，为策略提供比纯距离奖励更具物理意义的训练信号。

### 6.3 高度相关的球体分解

对于具有明显高度的动态障碍物，系统按障碍物水平尺度沿高度方向进行稀疏球体分解，球半径由水平对角尺寸确定。随后根据无人机与障碍物在预测时间窗内的垂直相对运动，只保留与无人机飞行高度相关的球体参与VO风险计算。

这种处理避免将细长障碍物粗略地看作一个覆盖全部高度的大椭球，也避免过密分割带来的额外计算。它能够更准确地区分“水平位置接近但高度错开”和“未来三维轨迹真正相交”两种情况，从而减少不必要的保守避让。

### 6.4 训练稳定性

VO权重在前20000个训练步内逐渐升高。先让策略建立基本的目标导航能力，再逐步强化未来碰撞约束，可以降低训练初期因风险惩罚过强而形成静止策略的可能性。

需要说明的是，当前总奖励中真正启用的是基于无人机实际速度和动态障碍物的 `reward_vo`。代码还计算了动作VO、静态VO和安全动作修正项，但它们在总奖励中的系数目前为0，不能作为当前实验模型的有效贡献进行宣称。

## 7. 世界模型启发的多时域预测辅助学习

### 7.1 设计动机

标准PPO主要利用即时奖励和价值回报更新策略。虽然折扣回报包含长期信息，但共享特征并没有被直接要求描述“未来会发生什么”。在大型墙体、L形和U形结构附近，单步动作往往不会立即造成碰撞，却可能使无人机逐步进入局部最优或死锁区域。

为此，本项目从世界模型的预测思想中提取轻量部分，在PPO rollout上构造监督标签，不建立完整的潜在动力学模型，也不执行想象轨迹规划。其准确定位是动作条件的多时域预测辅助学习，而非完整Dreamer或RSSM。

### 7.2 预测任务

辅助预测器以共享特征和当前归一化动作为输入：

```math
\hat{y}_{t,k}=f_{aux}(z_t,a_t), \qquad k\in\{1,3,5\}.
```

这里的预测目标来自当前观测—动作对之后的同一段PPO采集轨迹。因此，辅助预测器学习的是给定当前观测—动作对、后续动作继续由采集策略产生时的多时域轨迹结果，而不是当前动作的独立因果效应；它也不在部署时比较候选动作或执行反事实规划。

对于每个时间尺度，预测以下四类结果：

- 未来 `k` 步内是否发生碰撞；
- 未来 `k` 步内是否进入卡死状态；
- 未来 `k` 步内的最小前向净空；
- 未来 `k` 步内的累计目标进展。

碰撞和卡死使用二元交叉熵损失，净空和目标进展经过对称对数变换后使用Smooth L1损失。多步标签在rollout仍保持时间结构时生成，并在回合终止边界处停止传播，避免把下一回合的数据错误地作为当前轨迹未来状态。

### 7.3 联合优化

总训练目标为：

```math
L=L_{actor}+L_{critic}+L_{entropy}+\lambda_{aux}L_{aux},
```

其中 `lambda_aux=0.1`。辅助损失与PPO损失共同更新共享编码器，使特征不仅服务于当前动作和价值估计，还必须保留对未来碰撞、受阻程度和导航趋势有用的信息。

### 7.4 对大型障碍物绕行的作用

大型障碍物避障的关键并不只是避免眼前碰撞，而是尽早意识到当前方向会导致净空持续缩小、目标进展停滞或未来卡死。多时域辅助任务将这些未来结果显式反馈给特征编码器，使策略更容易形成具有时间延展性的环境表示。因此，无人机更有可能提前选择侧向绕行，而不是到达墙体中心后才被迫反复试探。

辅助分支仅在训练阶段参与损失计算。部署时Actor不读取预测结果，也不需要执行额外的模型滚动或在线搜索，因此保留了原始端到端策略的实时推理优势。

## 8. 训练环境与任务构造

训练使用NVIDIA Isaac Sim和GPU物理管线，支持大量无人机环境并行采样。仿真步长为0.016 s，对应62.5 Hz的环境决策频率。每次PPO rollout包含32步数据，并进行4轮更新和16个小批次训练。

除随机离散障碍物外，训练环境支持单墙、组合墙、L形和U形等多种大型障碍物布局。起点从地图边界随机采样，终点从起点所在边之外的其他边界采样，并检查起终点附近的静态净空。与起终点完全独立随机采样相比，该跨区域任务构造显著提高了无人机真正穿越障碍物区域的概率，使训练样本更集中地覆盖需要避障和绕行的有效场景。

代码还提供观测延迟、动作延迟、动作执行误差、LiDAR噪声与离散化、动态障碍物位置/速度/尺寸误差和检测丢帧等随机化接口。当前默认配置实际启用的是动作执行加性噪声和比例噪声，标准差均为0.03；其余噪声参数目前为0。后续可根据ROS部署端测得的误差分布逐步开启，而不宜把尚未启用的噪声写成当前模型已经验证的能力。

## 9. 相对NavRL的主要优势

### 9.1 从反应式避障提升为预测式避障

距离奖励通常在障碍物已经接近时才产生强信号，而TTC感知3D-VO能够在碰撞尚未迫近时识别危险相对运动。策略由“看见近障碍物再躲避”转向“识别未来碰撞趋势并提前调整”，尤其适合速度较高、方向变化明显的动态障碍物场景。

### 9.2 同时处理动态风险与长期局部最优

3D-VO解决的是动态障碍物未来轨迹冲突，多时域预测学习解决的是大型结构周围的长期决策不足。二者分别覆盖短中期碰撞风险和较长期绕行趋势，使算法不再只优化单一安全距离，而是同时关注未来安全性、通行空间和任务进展。

### 9.3 更符合三维无人机运动特性

算法显式考虑障碍物高度、无人机垂直速度和未来垂直相对运动。高度相关球体筛选既降低过度保守，又保留真正的三维碰撞关系，相比二维VO或统一大椭球近似更适合具有升降自由度的无人机。

### 9.4 鼓励有效退让而非盲目前进

当障碍物阻挡正前方时，算法降低短暂后退对应的目标进展惩罚，并对解除受阻状态给予正奖励。策略因而能够学习“先退后绕”的组合动作，而不是被持续前进奖励推向障碍物，或因惩罚冲突选择悬停。

### 9.5 训练增强但部署轻量

世界模型启发的预测能力只在训练中形成监督，部署时不增加辅助预测、轨迹采样或迭代优化环节。因此，该方法获得了部分模型预测思想带来的前瞻性，同时保持模型自由强化学习策略的低延迟和工程简洁性。

### 9.6 具有可解释的风险指标

VO风险可以由TTC、相对速度和安全尺度解释；辅助损失又分别对应碰撞、卡死、净空和目标进展。相比完全依赖总回报的黑盒训练，这些中间指标有助于定位模型究竟是动态风险判断不足、空间感知不足，还是长期进展预测不足，为后续参数调整和消融实验提供明确依据。

## 10. 实验结论与意义

现有仿真与实物试验结果显示，LP-Nav相较NavRL在动态障碍物导航任务中的成功率从74.3%提升至84.6%，即绝对提高10.3个百分点，说明基于未来相对运动的3D-VO奖励能够有效增强策略对动态冲突的提前识别能力。在大型障碍物场景中，模型还表现出死锁率降低和死锁后逃脱率提高的趋势，反映出多时域预测表征、停滞抑制和逃脱奖励对复杂绕行行为具有积极作用。

更重要的是，本项目的改进并非在部署端叠加一个高开销规划器，而是通过训练过程塑造无人机的“预测性避障直觉”。部署时策略能够根据当前感知直接产生动作，但其内部特征已经在大量未来风险监督下得到优化。这种“训练阶段增加认知深度、部署阶段保持决策简洁”的设计，为资源受限无人机在复杂动态环境中的实时导航提供了一条具有工程价值的技术路径。

## 11. 可用于汇报的创新点总结

1. 提出TTC感知的三维速度障碍物奖励，将动态障碍物的相对位置、相对速度、三维尺寸和有限时间窗统一纳入风险评价，实现从即时距离避障向未来碰撞趋势规避的转变。
2. 设计高度相关的稀疏球体分解方法，在控制计算量的同时提高细长动态障碍物的三维风险表达精度，减少因粗糙几何近似导致的过度避让。
3. 提出世界模型启发的动作条件多时域预测辅助任务，在不构建完整动力学模型的情况下，使PPO共享特征具备对未来碰撞、卡死、净空和目标进展的预测能力。
4. 设计兼顾目标进展、必要退让、停滞抑制和死锁恢复的奖励机制，使无人机能够学习更灵活的绕行动作，而非单纯追求最短方向上的即时前进。
5. 辅助预测分支仅在训练阶段使用，部署端保持原有策略推理结构，无需在线世界模型滚动或额外轨迹规划，在性能提升与实时性之间取得良好平衡。

## 12. 后续完善建议

为使报告和论文结论更具说服力，建议进一步补充以下实验：

- 在最终实验表中同时报告74.3%、84.6%及10.3个百分点的绝对提升，避免将百分点误写为相对百分比；
- 分别进行“NavRL”“NavRL + 3D-VO”“NavRL + auxiliary”“完整LP-Nav”消融实验；
- 对动态障碍物和大型静态障碍物场景分别报告成功率、碰撞率、死锁率和死锁后恢复率；
- 使用多个随机种子报告均值和标准差，证明提升不是单次训练波动；
- 报告部署端推理频率和单步延迟，验证辅助训练没有增加在线计算开销；
- 对VO预测时间窗、风险衰减系数、辅助损失权重和预测步长进行敏感性分析。

完成上述补充后，本项目可以形成一条较完整的证据链：3D-VO提升动态避障的提前量，多时域辅助学习改善大型障碍物绕行与局部最优问题，完整方法在仿真和实物平台上取得一致收益，同时保持端到端策略的实时部署能力。
